# 同步、重要信息与软件更新（桌面 1.4）

## 手机随手记

两种连接方式使用同一手机页面与电脑接收入口。手机无需填写 GitHub 账号，不把私人记录放在 GitHub 仓库里。

| 情况 | 行为 |
| --- | --- |
| 手机与电脑可连接 | 手机先写入 IndexedDB，再发送电脑；电脑收到后保存原文、声音和采集时间，再归档与同步 Obsidian |
| 手机离线或电脑关闭 | 手机保留记录；下次页面打开且电脑可连接时自动补传，不显示为已同步 |
| 同一条记录重试 | 使用手机生成的记录 ID 去重，电脑不会重复生成日记 |
| 电脑语音识别失败 | 手机显示已传电脑、待转写；电脑保留原录音，在手机栏目重试；不会伪造文字 |
| 安卓把页面挂起或关闭 | 无法保证后台重试；重新打开页面后继续 |

### 同一个可信 Wi-Fi

1. 电脑打开人生档案 → 手机随手记 → 开启接收。
2. 保留默认的家庭 Wi-Fi 地址，点击“显示配对二维码”。
3. 安卓相机扫码，在浏览器打开。用键盘的语音输入说话，或选择“导入 / 录制声音”。
4. 点“留下这个念头”。手机显示“已存手机”后，记录已经落到手机存储；成功传给电脑后才显示“已同步电脑”。

这个入口使用 HTTP，只有配对密钥鉴权，没有传输加密。仅在可信家庭网络使用，不做路由器公网端口转发。普通 HTTP 也无法注册可靠的离线 Service Worker 或使用网页麦克风 API；手机页面已说明限制。保存中的页面仍可记文字，重新载入需要电脑可连接。

### 外出即时同步与可离线重开的入口

推荐用 [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve) 在自己的私人网络内提供 HTTPS。个人套餐与限制以 [官方价格页](https://tailscale.com/pricing) 为准；本项目不收费、不代建账号、不租服务器。

1. 在 Mac 与安卓安装 Tailscale，登录同一个自己的账号。
2. 在 Mac 的 Tailscale CLI 执行：

   ```sh
   tailscale serve --bg http://127.0.0.1:43127
   ```

3. 按 Tailscale 官方指引开启私人网络 HTTPS，把得到的 `https://电脑名.网络名.ts.net` 地址填入人生档案的“私人 HTTPS 地址”，重新显示配对码并扫码。
4. 首次连接电脑、完整载入手机页面后，添加到手机主屏幕。HTTPS 页面缓存完成后可离线重新打开，IndexedDB 会保留记录；恢复连接并打开页面后补传。

Serve 对私人网络内可访问的设备开放，**不要使用公开的 Funnel**。同一账号不等于其他共享设备绝对可信，仍需要配对密钥。证书公开透明日志可能披露设备的证书域名，依照 Tailscale 官方 HTTPS 说明选择设备名。

同 Wi-Fi 地址与私人 HTTPS 地址属于不同浏览器来源，手机存储也彼此独立。更换入口前先把旧入口的待同步记录传完或导出备份。不要清除网站存储；卸载浏览器或清理站点数据会影响手机本机记录。

当前只提供网页随手记，没有安卓原生 APK；本项目的接口测试与桌面浏览器验证不等于安卓手机、移动网络或锁屏后台实测。

## Obsidian 自动同步

- 选择已有知识库后，保存日记、追加和高亮时同步，并每分钟重试。知识库不可用时日记仍在本机 SQLite，设置显示失败状态。
- 生成 `人生档案/日记/YYYY/YYYY-MM-DD.md`，同一天多条记录放在同一文件，按原采集时间排列；录音副本在 `人生档案/录音`。
- 应用维护带有 `life-archive:begin/end` 标记的区域。文件末尾“手动补充”区域可自由写，不被应用覆盖。
- 如果手动修改了应用维护的区域，程序保留已有文件，写出 `日期.待合并.md`，请在 Obsidian 中人工合并；不会用新内容强行覆盖人工修改。
- 在人生档案追加旧日记会反映到 Markdown；直接在 Obsidian 的手动区写的文字不会自动反向写回人生档案数据库。当前是归档同步，不是通用双向编辑引擎。
- 仅本机日记、保险箱内容和匹配凭据格式的日记不参与同步。自动检测不是完整的敏感信息识别，录入私密内容请明确勾选“仅本机”。
- 为避免误上传，程序拒绝把日记自动同步到 Git 仓库内部的 Obsidian 知识库。

## 重要信息保险箱

密码、重要事件、个人重要信息可单独保存在保险箱。整个内容含标题均以 AES-256-GCM 加密；每次写入使用独立随机 IV，主密码经 scrypt（N=32768,r=8,p=1）派生密钥。磁盘文件只含版本、盐、IV、认证标记与密文。

主密码不保存、不发送、无法找回。首次请设置至少 10 位的主密码并自行妥善保管。保险箱只在主动解锁后将内容留在进程内存，闲置 5 分钟、系统锁屏、退出时清除密钥引用并锁定；界面在锁定检查时清空内容。它不参与 Obsidian、普通搜索、知识归纳或手机接口。

完整备份包含 `private-vault.json` 密文。备份可用同一主密码解密；恢复到另一台机器仍需主密码。不把主密码和密文备份放在一起。本版没有独立安全审计或跨设备密码同步。

## 软件自动更新

默认启动后和每六小时读取本项目公开 GitHub Releases；用户可关闭。只选择比当前版本高、架构匹配、非草稿、非预发布且具备 GitHub SHA-256 摘要的 ZIP。下载完成校验字节数与摘要；安装前检查 ZIP 路径、Mac 签名完整性、Bundle ID 与版本。

下载通过后显示“重启并安装更新”。点击前保存草稿，安装辅助程序等待应用退出，仅替换 `.app` 程序，保留旧 App 供回退，不触碰独立数据目录。当前不是强制静默重启，不会降级到 GitHub 上较旧的版本。

更新器只读取版本与下载软件，不向 GitHub 发送日记、音频、保险箱、知识库路径或文件。请求会像普通网络访问一样携带 IP 与公共更新器 User-Agent。开源发布使用显式文件清单，`.runtime`、数据库、录音、导出、密钥和知识库不进入程序包或 Git。

公开 Mac 包目前采用 ad hoc 签名，没有 Apple Developer ID 公证；更新校验确认下载来源、文件摘要、包身份及签名完整性，不能替代 Apple 公证。首次系统权限与系统拦截仍由 macOS 决定，不承诺绕过。
