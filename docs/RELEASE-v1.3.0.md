人生档案 1.3 将公开产品恢复为已确认的光门电影皮肤，并补齐“记录之后如何回看自己”的主要流程。免费开源，MIT 许可，面向每个人，产品不展示个人介绍。

- 首页恢复黑色光门人物、宋体、电影感留白；通用版与 Mac 工作区统一视觉。
- 经历可补充人物、主题标签、感受、地点、主题与置顶；搜索人物或标签，沿人物、主题回到原始经历。
- 旁观自己：12 周生活纹理、主题分布、本周回望、Markdown 回顾导出；只统计已确认且未删除的记录，每项观察都能回看原始经历。
- 人生选择：保留处境、选项、实际选择、理由、期待、担心、回望日期与后来结果；关联已确认经历，支持复盘和回收站。
- 完整备份 v2 保存选择记录、经历与原件，兼容 v1 与 Mac 文字导出。通用版可手动导入 ActivityWatch buckets JSON，减去同设备离开时段，保持待确认。
- 日记提醒仍默认关闭，使用者自选时间、强度、10 分钟稍后和当日完成。

Mac 安装包适用于 macOS 13+ Apple 芯片。下载 DMG 后将“人生档案”拖入“应用程序”。采用 ad hoc 签名，尚未 Apple Developer ID 签名和公证，首次打开可能受系统限制：https://support.apple.com/en-us/102445

这是公开测试版。没有生成式性格分析、影音识别/转写、所有 App 全量读取或自动云同步。网页定时提醒需要页面运行；页面关闭时可自行导入系统日历提醒，日历与网页设置独立管理。Mac 程序需保持运行。
