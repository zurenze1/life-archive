# 人生档案 1.2 · 免费开源与日记提醒

面向每个人的免费开源工具：个人档案保存在使用者自己的设备，不预设个人账号。

## 本次更新

- 移除产品页面、分享图、安装包元数据与说明中的个人署名和个人网站介绍。
- 正式采用 MIT 开源许可，可免费使用、修改和分发；第三方依赖保留自身许可证。
- 新增日记提醒：默认关闭，可选每天的本地时间、普通或强提醒；支持测试、延后 10 分钟和今天已写。
- 强提醒会弹出日记窗口并请求通知提示音；未处理时每 5 分钟再提醒，直到处理或关闭。通知与声音依系统权限、勿扰模式和浏览器限制而定。
- Mac 版新增直接写日记，保存当天日记后当天不再提醒。日期筛选与导出按使用者当前时区，支持夏令时跨日。
- 手机通用版可下载每日提醒并导入系统日历。导入后在系统日历中管理，不与网页开关或日记状态同步。

## 开始使用

手机与电脑：[免费通用网页版](https://zurenze1.github.io/life-archive/app/)。
Mac：下载 `LifeArchive-1.2.0-arm64.dmg`，将“人生档案”拖入“应用程序”；适用于 macOS 13+ 的 Apple 芯片 Mac。也提供 ZIP 和 SHA256SUMS.txt。

在 Mac 的“设置与数据 → 日记提醒”，或通用版顶部“日记提醒”，选择开关、时间和强度，保存即可。

## 运行范围

Mac 关闭窗口留在菜单栏仍可提醒；退出、关机或睡眠时无法提醒，重新打开或解锁后补当日。网页需保持页面运行，关闭、锁屏或后台冻结可能使提醒延迟或停止。系统日历提醒由日历应用和系统通知设置管理。

本版本仍采用 ad hoc 签名，尚未经过 Apple Developer ID 签名与公证；首次下载可能被系统拦截，参考 [Apple 官方说明](https://support.apple.com/en-us/102445)。没有绕过系统权限、自动云同步或所有 App 全量读取。
