# 人生档案 1.0 · Mac 本地测试版

少打字，也能把自己电脑上可读取的生活线索整理为可搜索的时间线。

## 下载安装

- `LifeArchive-1.0.0-arm64.dmg`：推荐安装包，打开后将「人生档案」拖入「应用程序」。
- `LifeArchive-1.0.0-arm64.zip`：应用压缩包。
- `SHA256SUMS.txt`：安装包校验文件。

需要 macOS 13+、Apple 芯片 Mac。Intel Mac、Windows、安卓和 iPhone 独立安装包尚未提供。

## 本机验证

11 项回归测试通过；独立应用启动、SQLite、前台应用接口、打包后 PDF 提取、中文搜索、暂停、JSON 导出、应用资源签名、DMG 与 ZIP 完整性均已检查。

安装包只包含程序，没有个人档案数据库、录音、账号配置或开发期采集材料。每位使用者的数据保存在自己的电脑。

本次修复了浏览器时间整数溢出、Excel 空列错位、浏览器独占数据库读取，以及应用资源签名不完整的问题。

## 使用范围

可以自动整理已适配且可授权读取的应用使用线索、浏览记录和文件；支持搜索、原件打开、文件导入、主动录音、暂停与本机导出。受保护的聊天库不解密，手机接入以实际连接和已适配来源为准。更多说明见仓库 README 与功能范围文档。

这是首次公开测试版本，采用 ad hoc 签名保证包资源完整，尚未经过 Apple Developer ID 签名和公证。系统可能阻止首次打开；请按 [Apple 官方说明](https://support.apple.com/en-us/102445)判断是否信任并打开。其他电脑的兼容性仍需更多实际使用验证。
