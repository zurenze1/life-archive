# 1.3 开源研究与实现对应

本次围绕原产品承诺找缺口：材料、时间线已经存在，但人物与主题回看、自我观察和选择复盘尚未完整串联。视觉沿用使用者已确认的光门电影皮肤，未更换成参考项目的界面。

| 研究来源 | 有益的设计 | 人生档案中的实际实现 |
| --- | --- | --- |
| [Memos](https://github.com/usememos/memos) | 低负担快速记录、标签、时间线、置顶、可导出 | 不强制标题；人物/主题搜索；置顶经历；完整备份与 Markdown 周回顾 |
| [Monica](https://github.com/monicahq/monica) | 记住同行的人及共同经历，以关系找回过去 | 使用者主动标注人物后，生成可点击的人物档案；每条关系线索回到原始经历 |
| [ActivityWatch](https://github.com/ActivityWatch/activitywatch) | 保存前台事件、区分离开与活动；来源数据保留在设备 | 手动导入 buckets JSON；处理 currentwindow 与同 hostname 的 afkstatus；重叠离开区间先合并；保留待确认，避免冒充实际行为 |

实现是围绕公开需求独立编写的原生 JavaScript，没有复制上述项目源码，也未将其服务器、GPL/AGPL 组件或其他依赖并入 MIT 包。项目链接用于说明研究来源，不代表合作或官方集成。

人物、主题、感受来自使用者主动填写；统计只使用已确认且未删除的经历。自我观察可回看证据，不诊断人格或心理状态。选择日志用于保留个人经验，不替使用者做重大决定。

## 仍未接入

- 生成式 AI 性格分析、影音转写、扫描件 OCR。
- 所有手机应用内部数据的全量读取与跨设备自动同步。
- 手机、Windows 等系统的原生自动采集安装包。

这些不会在界面中伪装成已经接通。手机与其他电脑可使用免费通用网页；Mac 保留自动采集与本机数据管理。

研究与实现日期：2026-10-06。
