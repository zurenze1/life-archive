# 人生档案通用网页版 1.1

面向大众的免费入口：https://zurenze1.github.io/life-archive/app/

## 设备与真实范围

iPhone、iPad、安卓、Mac（含 Intel）、Windows 和 Linux 可通过支持 JavaScript / IndexedDB 的现代浏览器使用。通用版无需账号，记录和原件存于当前浏览器，不自动上传。浏览器或系统的访问限制、网络可达性仍会影响使用；没有声称每款设备或内置浏览器均已验证。

基础能力包括文字记录、日期与关键词搜索、文件导入、DOCX/XLSX/PDF 文字提取、照片影音原件保存、主动录音、完整备份、手动迁移、回收站恢复。部分浏览器支持添加到桌面或拍照；媒体无法预览时可下载原件。

网页版不会读取其他 App 的内部聊天和订单，也没有自动云同步、影音识别、声音转写或扫描件 OCR。Mac arm64 自动采集端 1.0 仍单独提供。Windows / Intel Mac / 手机的原生采集端和应用商店安装包尚未发布。

## 数据保留

IndexedDB 保存文字与原件；记录与附件用同一个事务写入，失败不会显示保存成功。重复文件按内容 SHA-256 去重，备份按来源标识去重。移除记录仅放入回收站，不自动永久删除。

完整 JSON 备份包含原件的 Base64 内容。大档案按预计大小自动分批，每部分需分别下载并导入。单附件最多 50 MB；备份每次导入最多 100 MB / 10,000 条。缺失原件、无效日期或不支持的云端附件 / 决策格式会明确拒绝，不静默宣称完整迁移。旧版分类、人物、标签、地点和证据关联保留在 legacy 字段中。

清除网站数据或系统回收存储可能丢失档案。不同设备、浏览器和桌面模式可能独立存储，使用者需保留备份。共用浏览器没有独立登录锁。页面不把用户文字作为 HTML 执行，未知 / SVG 类型仅作为下载原件，不嵌入执行。

## 离线与依赖

Service Worker 仅控制 `/life-archive/app/`，缓存应用静态资源，不缓存个人备份或访问原私人 Sites。自有 JS 模块和样式使用同一构建版本；旧缓存只清理本应用自己的命名空间。PDF.js / fflate 从锁定 npm 依赖复制并附许可证，不调用外部 CDN。

首次联网完成离线准备后，核心功能可以离线使用。PDF 所需的特殊字符映射与字体按需缓存，未缓存资源可能限制新的 PDF 解析；原件仍可保存。离线不是多设备同步。
