# 人生档案 1.4：语音日记与个人知识沉淀

本版以主动记录为核心。每天 21:00 提醒、语音转文字、原文与归纳分开、原话知识卡片、时间戳和完整备份取代了日常自动采集界面。

## 每天如何使用

1. 直接“说几句”，或按“今天发生了什么 / 学到与想到 / 接下来想做的事”回答。每个问题可录一段，也可文字补充。
2. 停止录音后，原始声音先写入本机，再进行本地识别。人名、数字等请回听检查；可校正识别文字，原始转写另外保留。
3. 点击“查看原话整理”，核对每一点。保存后可在“我的日记”找到原文、录音和整理结果。
4. 在“我的日记”按原话、标题、标签或日期查找，日期索引可快速定位；也可只看有高亮的日记。
5. 打开旧日记点击“继续补充”，补充可用语音或文字，每次另带时间戳，旧原文与片段标识保留。选中原文，再点击“高亮选中文字”。
6. 在“提醒与备份”选择 Obsidian 知识库，自动同步原文、归纳、补充、高亮与录音。
7. 对想长期保留的一点，点击“留为知识卡片”。卡片只接受日记原文中存在的文字，随时能回到来源。

## 21:00 强提醒

默认每天本地时间 21:00。强提醒全屏置顶，空白内容不能标为完成；当天在提醒时间之后保存了日记，才完成当晚记录。没有“今天已写”空点跳过。紧急情况可延后 5 分钟；也可在设置有意识地关闭强提醒或每日提醒。

Mac 安装版通过本机 LaunchAgent 到点请求打开应用，同时应用运行期间每秒检查。首次启动配置定时启动，失败会在设置中明确显示。退出应用后定时任务仍可在本机登录且可运行时请求打开；实际关机或睡眠不能保证准点，恢复后检查补提醒。不会锁住操作系统、绕过睡眠或自动打开麦克风。

## 归纳的准确含义

当前使用可追溯的原话摘录与归类：按提问组织内容，自由说时只根据明确的表达归类；省略完全重复的句子与独立语气词。每一点保存来源片段与起止位置，完整原文始终单独保存。

不使用生成模型推测原因、情绪、性格或结论，不把“没做”改成“做了”，不把“不确定”改成确定。它不是自动改写、润色或心理画像。多余口语表达若影响意思判断，会宁可保留，之后可由本人确认。

## 本地语音识别

接入 [FunASR](https://github.com/modelscope/FunASR) 与 [SenseVoice](https://github.com/QwenAudio/SenseVoice)。不使用云端转写或付费 API。

- 已安装本地 FunASR 转写程序时，在“提醒与备份”选择可执行程序。接口为 `transcribe <audio-file> --out <text-file> --keep-fillers`。
- 自动发现当前用户 `Library/Application Support/人生档案/speech-runtime/bin/transcribe` 或既有 FunASR Skill 的转写入口；不是从系统里搜索私人资料。
- 对具备 `venv/bin/python` 与 `.modelscope` 缓存的本地环境，使用应用内 `funasr_local.py`，直接加载已存在的 SenseVoiceSmall、FSMN-VAD 和标点模型，避免每段录音都联网检查模型。
- 新电脑需要先按 FunASR 官方说明准备环境和模型，再选择转写入口。模型不塞进桌面安装包；代码许可与模型权重许可分别遵守，参见上游模型卡。
- 支持常见 WAV / M4A / MP3 / WebM 等格式，实际解码取决于本地 FFmpeg 或 macOS 转码支持。识别失败保留录音，不伪造转写；可以重试、导入录音或先写文字。

当前版本不会识别说话者身份，不使用模型的情绪识别输出推断个人状态。普通首次录音会触发 macOS 麦克风授权；已拒绝时给出设置指引，不循环申请。

## 旧数据与权限

停止前台应用采样、文件夹自动扫描、浏览器与其他应用数据的后台读取。仅在主动录音和选择导入时读取所需资料。

升级前保存 SQLite 一致性备份至本机数据目录的 `backups/before-journal-1.4.sqlite`，再移除 `kind=activity` 的应用使用记录。其他旧材料与选择记录保留；旧材料在设置的历史区按需查询。不会把旧线索当成新知识，也不将私有材料上传到 GitHub。

## 数据与备份

新日记、草稿、原始转写、知识卡片与录音元数据保存于原本机 SQLite；录音在 `data/recordings`，主动导入文件的副本在 `data/attachments`。文件与目录使用仅本用户读写的权限。日期和创建时间由程序自动生成。

“导出完整备份”选择一个目录，生成包含 SQLite、录音、附件、日记 JSON 与 Markdown 的文件夹。旧版索引所指向的外部照片或文档没有自动复制进备份，需要另行保留原件。录音等包含私人内容，导出前不会上传。

## 开源借鉴

- [Memos](https://github.com/usememos/memos)：借鉴轻量记录、按时间找回与保留数据所有权的思路；未搬入其 Go 服务或前端代码。
- [voice-memo-to-obsidian](https://github.com/mobob/voice-memo-to-obsidian)：参考转写与摘要分区和可留作知识的结构，未使用其云端 Gemini 上传流程或复制其代码。
- FunASR / SenseVoice：实际使用已安装的开源语音识别依赖与本地模型。模型权重遵循各自模型卡许可，本项目不重新分发权重。

新增界面、定时策略、数据层和原句归纳由本项目编写，MIT 许可；依赖和模型许可独立保留。
