# 本机测试记录

日期：2026-10-06。测试环境：Apple Silicon Mac，macOS 26.6，Node.js 24.21.0。

## 已通过

- 11 项隔离夹具测试：持久化与重启恢复、搜索、导出去除私有字段、重复扫描去重、源库只读、独占 WAL 数据库的稳定只读副本、Chrome 微秒大整数、Apple 信息纳秒大整数、验证码隐藏、采集目录排除、CSV 多行与引号、Excel 空列、DOCX 提取、超限压缩包拒绝、单个来源失败隔离。
- 发布期间修复并复测了浏览记录时间整数溢出和 Excel 空列错位问题。

## 安装包验证

- 独立安装包启动：Electron 44.5.1、Node 24.21.0、SQLite 3.53.4 与 Koffi 前台应用接口均正常。
- 签名后安装包中的 PDF 文字提取通过，使用合成的单页 PDF 测试。
- 同一份桌面代码的界面验证：中文搜索、暂停采集，以及原生保存对话框导出 JSON 均通过。验证使用隔离目录中的合成材料。
- 采用 ad hoc 签名封装资源，`codesign --verify --deep --strict` 通过。尚未使用 Apple Developer ID，也未公证。
- 应用包内 600 个文件，未包含个人档案数据库、录音、账号配置、测试夹具或开发期数据；关键程序和界面文件与发布源码相同。
- DMG 校验和与 ZIP 压缩数据检查通过；发布页附 SHA-256 校验文件。

测试不会证明所有应用均可读取，也不会证明其他系统与硬件已经通过验证。首次发布只提供本机验证的 Mac arm64 安装包。
