# 1.0 功能范围

| 来源 | 实际能力 |
| --- | --- |
| 电脑应用 | 检测应用清单，运行期间采样前台应用名称和估计使用时间 |
| 浏览记录 | 读取可访问、已适配的 Chrome、Edge、Brave、Arc、Firefox、Safari SQLite 历史库；每份最多最近 20,000 次访问 |
| 文档 | 提取 TXT、Markdown、CSV、ICS、DOCX、XLSX、PDF 可读文字；每文件最多解析 12MB、PDF 最多 30 页、Excel 最多 10 表且每表 2,000 行 |
| 照片与影音 | 保存原件名称与时间索引，可打开原始文件；当前无 OCR、画面识别或声音转写 |
| 订单导出文件 | 按 CSV / XLSX 明确的文字日期与商品字段整理；数值型 Excel 日期尚未转成事件日期 |
| Apple 信息、日历、照片图库 | 在系统权限和数据库结构允许时读取部分文字、日程和照片索引 |
| 微信 | 检测本地目录与保护状态；加密聊天库不解密，可整理用户导出的材料 |
| iPhone | 检查本机可访问的未加密 Finder 备份，读取已适配的部分短信、Safari 与相机索引 |
| 安卓 | 检查已有官方 adb 与已授权设备，读取应用清单；当前无完整聊天、订单或使用历史接入 |

每次文件扫描最多 15,000 个文件、目录深度最多 12。较大的文件、旧 DOC / XLS 仅保留原件索引。扫描会跳过隐藏项、常见凭据文件、依赖目录、符号链接和本工具自己的数据。

工具显示可读取、部分可读取、访问受限、未发现、未连接或尚未适配等实际状态。来源读取失败时，其他来源仍继续处理。

订单不能证明实际吃过或用过，日程不能证明已经完成，文件修改时间也不等于生活事件发生时间。自动线索在导出的档案中标为待确认。
