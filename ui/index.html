自动整理文件夹

每 30 分钟检查一次。文件夹内的照片、影音和文档会进入本机档案。原始文件保留在原处。

后台与启动

关闭窗口后在菜单栏继续运行；选择“退出并停止采集”才会退出。锁屏、空闲或睡眠时停止记录前台应用，恢复后继续。此工具不会自动录屏或录音。

自己的数据，自己掌握

所有记录保存在本机，不自动上传。导出的 JSON 可备份，也可在网页版手动导入文字线索；照片、视频和录音原件不会随 JSON 上传。

1.0：支持 Word / Excel / PDF 可读文字和常见媒体原件索引。旧 .doc / .xls、扫描件 OCR、影音转写、加密聊天库和手机实时全量同步尚未接入。不同电脑的用户数据彼此独立。

手机接入
