CATCH A THOUGHT, WHEREVER YOU ARE

灵感来了，手机也能留下。

手机先存，连接电脑后自动补传。电脑收到后，归档并同步 Obsidian。

电脑运行时提供私人接收入口，不读取手机其他数据，不向手机开放整份档案或密码保险箱。同 Wi-Fi 的普通地址使用 HTTP，请仅在可信网络使用。

用安卓相机扫码；配对链接相当于收件密钥，请勿分享。

回家同步与外出即时同步

同 Wi-Fi：手机扫码即可记录，页面打开时自动补传。外出即时同步和离线重新打开：手机与电脑加入同一 Tailscale 私人网络，用 HTTPS 连接，添加到手机主屏幕。

两种方式共用同一接收入口。电脑关机时手机先存；电脑上线后，打开随手记即可补传。安卓限制后台运行，不承诺页面关闭后仍能同步。

电脑设置命令（需要已安装并登录 Tailscale）：

tailscale serve --bg http://127.0.0.1:47831

这不会将页面公开到互联网。把得到的私人 HTTPS 地址填入上方，再扫码。

KEEP A LITTLE SPACE FOR YOURSELF

把今天，留给自己。

提醒、语音和完整备份，由你掌握。

每日语音日记提醒

默认每天 21:00。当天到提醒时间后完成日记才停止催促，不能仅点“已写”跳过。可按自己的需要关闭强提醒。

电脑关机或真正睡眠时无法准点弹屏；保持登录、电脑清醒时可运行，恢复后检查补提醒。系统声音受音量与勿扰模式影响。

自动同步到 Obsidian

按日期保存到“人生档案 / 日记”，录音一起保留。日记补充和高亮会自动更新；手动补充区不会被覆盖。识别到密码等凭据格式的日记会跳过同步。保险箱始终不参与。

软件自动更新

只从本项目的 GitHub Release 下载软件并校验 SHA-256。安装只替换程序，私人档案与保险箱保存在独立数据目录。没有私人数据上传接口。

本地语音识别

使用 FunASR / SenseVoice。语音不上传云端，没有额外接口费；识别失败也会保留原始录音。首次准备及模型许可见使用说明。

保留原文，完整备份

导出数据库、录音、主动导入的文档、日记 JSON 与 Markdown。旧版索引指向的外部原件不包含在备份内。它们包含私人内容，请保存在你信任的位置。

旧版历史材料（自动采集已停用）

保留旧文件和浏览线索供查找；不再新增。应用使用记录已在迁移备份后移除。
