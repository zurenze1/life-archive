工具介绍常见问题项目与开源使用教程

快速开始 · 无需注册

人生档案怎么用？先留下一件事，
再慢慢看见自己。

先选网页版或 Mac 采集端。写日记、导入已有材料，之后用时间线找回过去，用回顾和选择复盘积累个人经验。

打开免费通用版 →

手机与电脑：三分钟开始记录

  1. 打开通用版，点击“记下这一刻”，写一件今天发生的事；也可点击“导入已有材料”，选择照片、音频或文档。
  2. 补充人物、主题、地点与感受，确认真实发生的经历。之后按人物、主题、日期或关键词找回。
  3. 打开“日记提醒”，自选开关、每天时间与提醒强度，再保存。默认关闭，可以先测试。
  4. 积累后进入“旁观自己”，查看 12 周生活纹理、本周回顾和主题分布；可导出 Markdown 回顾。
  5. 遇到重要选择，进入“人生选择”，保存处境、选项、理由、期待与担心，关联经历；后来补充结果。
  6. 定期点击“备份与迁移”导出完整备份；换设备先传输备份，再导入恢复。

Mac：安装可授权的电脑线索采集端

  1. 需要 macOS 13+ 与 Apple 芯片 Mac，从 1.3 下载页下载 DMG。
  2. 打开 DMG，将“人生档案”拖入“应用程序”；首次打开如被拦截，参见 Apple 官方说明。
  3. 在“采集来源”查看实际读取状态，在“设置与数据”调整文件夹与来源，由自己选择是否授权。
  4. 补充日记、人物和主题；自动线索需你回看确认。关闭窗口后留在菜单栏，选择退出则停止采集与提醒。

忘写日记：选择提醒方式

普通或强提醒由你选择；强提醒提供弹窗与提示音，未处理时每 5 分钟再提示，可以延后 10 分钟或确认今天已写。保存当天文字日记后停止当天催促。

Mac 需保持运行。网页关闭、锁屏或后台冻结不能保证准时；可下载每日提醒并导入系统日历。日历提醒独立，修改或删除需在系统日历操作。

保存在哪里，怎样备份？

通用版保存在当前设备的浏览器，不自动上传或云同步；不同浏览器和桌面模式可能独立存储。清除网站数据前先导出包含原件的完整备份。

Mac 的 JSON 导出只含文字线索与清理后的链接，不含原件。完整备份 Mac 档案时，退出程序后保存整个本地 data 文件夹；可从“查看本地数据”找到它，另外保留原始文件。

设备与功能范围

iPhone、iPad、安卓、Mac、Windows、Linux 可通过支持 JavaScript 和 IndexedDB 的现代浏览器使用。独立安装包目前仅提供 Apple 芯片 Mac。录音、拍照和媒体播放取决于实际浏览器支持。

DOCX、XLSX 与 PDF 可提取可读文字；媒体保存原件。自动影音识别、录音转写、所有 App 内容采集与生成式性格画像尚未上线。
