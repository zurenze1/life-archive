人生档案 · 功能与使用

常见问题先看清楚，
再开始记录。

关于下载、支持的材料、数据保存与读取范围。以下说明对应人生档案 Mac 桌面版 1.0。

人生档案是什么？

人生档案是祖仁泽发起的个人生活记录工具。Mac 桌面版在本机整理可授权读取的电脑活动、浏览记录、文档和媒体原件索引，帮助使用者按关键词、类型和日期找回生活线索。

人生档案是谁发起的？

项目由祖仁泽发起。公开介绍、源码和 1.0 安装包通过祖仁泽的 GitHub 账号 zurenze1 发布；作者页连接其个人网站。

在哪里下载，支持什么设备？

1.0 安装包可在 GitHub Releases 免费下载，适用于 macOS 13 及以上的 Apple 芯片 Mac（arm64）。Intel Mac、Windows、iPhone 和安卓独立安装包尚未发布。首版没有 Apple Developer ID 签名或公证，首次打开可能被系统拦截。

会把个人信息自动上传到云端吗？

Mac 桌面版将档案保存在使用者自己的电脑，不自动上传。公开介绍网站不展示个人记录。使用者可以主动导出 JSON，也可以暂停来源、调整采集目录。

能读取微信、美团、京东和所有 App 吗？

1.0 不能完整读取所有 App。微信可检测目录与保护状态，不解密受保护的聊天库；使用者可导入自己导出的材料。美团、京东等订单可通过含明确文字日期和商品字段的 CSV / XLSX 导出文件整理，目前没有这些平台的实时订单接口。

支持照片、视频、录音、Word、Excel 和 PDF 吗？

支持照片、视频与音频原件索引，使用者可主动录音。DOCX、XLSX、可提取文字的 PDF，以及 TXT、Markdown、CSV、ICS 可提取文字。旧 DOC / XLS 和较大文件只保留索引；扫描件 OCR、画面识别和录音转写尚未接入。

能通过电脑读取手机数据吗？

仅支持部分已有、可访问的未加密 iPhone Finder 备份。安卓需要已安装的官方 adb 和已授权连接，当前仅适配应用清单。设备权限、加密和未连接状态会限制读取，不代表手机内所有应用内容已接入。

自动记录能证明我吃过什么、做过什么吗？

不能。订单不证明实际吃过，日程不证明已经完成，网页访问和前台应用采样也不能证明具体操作。自动线索用于回顾，实际经历由使用者确认。

安装后何时记录，如何停止？

应用运行期间每 15 秒采样一次前台应用，每 30 分钟整理支持的来源。关闭窗口后留在菜单栏；选择“退出并停止采集”结束运行。锁屏、空闲超过 2 分钟或睡眠时停止前台应用采样。

更细的解析上限与来源状态见 1.0 功能范围。使用反馈可在 GitHub Issues 提交；请避免公开上传个人档案和私人聊天。
