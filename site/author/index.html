人生档案（Life Archive）由祖仁泽发起，是面向每个人的免费开源生活记录与个人经验管理工具。每个人整理自己的经历，档案留在自己的设备。

为什么被设计出来？

日记常常忘写，照片、文件和片段感受散落在不同地方。过了很久，我们对过去只剩模糊印象；重大选择到来时，难以找回自己当时的理由与后来结果。

祖仁泽发起这个项目，希望少一点记录负担，多一点理解自己的依据。先留下一件真实的事，再把分散材料慢慢连成自己的故事；不用一次写完人生。

祖仁泽与这个项目的关系

祖仁泽是人生档案的项目发起人，公开 GitHub 账号为 zurenze1。工具面向所有使用者，无需注册，档案保存在各自设备。发起人说明介绍项目来源，不包含使用者的私人档案。

核心价值

通过日记提醒与材料导入减少记录负担，通过时间线找回过去，通过人物、主题和感受观察变化，通过理由与结果复盘人生选择。实际能力以当前发布功能为准，不把自动线索当成已确认经历。

自由使用，共同完善

项目采用 MIT 许可，可以免费使用、修改与分发，分发时保留版权和许可声明。第三方依赖仍遵循各自许可。欢迎提交问题与改进建议；不要把私人档案上传到公开仓库。
