祖仁泽与人生档案

人生档案由祖仁泽发起，通过 GitHub 账号 zurenze1 发布公开源码与安装包。项目的目标是让使用者更容易留住生活线索，回顾自己的经历，少一些重复输入。

项目面向大众：免费通用网页版 1.1 支持手机与电脑的记录、原件导入、文档解析、录音与备份；另提供 Mac 1.0 本地采集端，整理已适配、可授权读取的电脑活动、浏览记录、文档和媒体原件索引。真实经历和线索含义仍需要使用者确认。

“祖仁泽”是发起人的姓名；“人生档案”是工具名称，英文项目名为 Life Archive。
