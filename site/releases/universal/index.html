通用版现在可以做什么

  • 记录文字，按日期、类型与关键词查找时间线。
  • 导入照片、视频、录音及文件，保留原件；可用设备还能拍照和直接录音。
  • 提取 DOCX、XLSX、PDF、TXT、Markdown、CSV、ICS 的可读文字。旧 DOC / XLS 只保留原件。
  • 导出包含文字与原件的完整备份，在另一台设备导入；大档案自动分批。
  • 支持的浏览器可添加到桌面；离线缓存准备后可使用核心功能。
  • 移除的记录可从回收站恢复，不自动永久清空。

各设备怎么开始

直接打开通用版链接即可使用。iPhone / iPad 建议使用 Safari，并可通过分享菜单“添加到主屏幕”；安卓建议 Chrome。电脑可使用现代浏览器，支持时可安装为桌面网页应用。

基础使用需要 JavaScript 与 IndexedDB。录音、拍照、安装入口、媒体格式和浏览器存储取决于设备与浏览器能力。不支持的媒体仍可下载原件；内置浏览器受限时，可在系统浏览器打开。

自己的档案，自己保留

档案保存在当前设备的浏览器，不自动上传。无需账号意味着这里没有登录锁，共用该浏览器的人可能访问档案。不同设备、不同浏览器或添加到桌面模式可能独立存储，当前不提供自动云同步。

清除网站数据或系统回收存储可能丢失档案，请定期导出完整备份。备份含私人文字与原件，不要公开分享。可以请求浏览器保留存储，但浏览器可能拒绝。

自动采集与当前范围

通用网页不会直接读取其他 App 的聊天或订单。可导入自己导出的文件；Mac arm64 用户可另用 1.0 自动采集端。其他系统的原生采集、影音识别、转写和自动同步尚未上线。

单个附件最多 50 MB；文档解析最多 12 MB / 30,000 字符；PDF 最多 30 页；Excel 最多 10 个工作表、每表 2,000 行。备份每次导入最多 100 MB、10,000 条。文件日期来自修改时间，是待确认的线索；订单不证明实际食用。
