Mac 桌面版 1.2

写日记，也留住线索。

自动整理可授权读取的电脑线索，或主动写下今天。免费开源，数据留在本机。

下载安装包 ↗

安装

需要 macOS 13+ 与 Apple 芯片 Mac。下载 DMG 后将“人生档案”拖入“应用程序”。采用 ad hoc 签名，尚无 Apple 公证；首次打开可能被系统拦截，参见 Apple 官方说明。

可设置的日记提醒

设置与数据 → 日记提醒。默认关闭，可选时间和强度。关闭窗口留在菜单栏仍可提醒；退出、睡眠或关机时无法提醒，重新打开或解锁后补当日。暂停采集不影响提醒。系统通知受权限与勿扰模式影响。

来源与备份

可整理支持的浏览记录、文件与前台应用线索；支持日记、原件打开、录音、暂停和 JSON 导出。个人档案与原件不包含在公开安装包里。详细范围见 功能说明。
