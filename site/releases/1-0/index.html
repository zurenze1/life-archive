人生档案 · 公开版本

Mac 1.0从自己的电脑，
开始留住生活线索。

祖仁泽发起的人生档案，现提供 Mac 本地测试版。免费下载安装，个人档案保存在使用者自己的电脑。

发布说明：2026-10-06 · 祖仁泽

前往 GitHub 下载 ↗

下载安装

  1. 在 GitHub 发布页下载 LifeArchive-1.0.0-arm64.dmg。
  2. 打开 DMG，把“人生档案”拖入“应用程序”。
  3. 打开应用，在“采集来源”查看读取状态，在“设置与数据”调整采集目录。

需要 macOS 13+ 与 Apple 芯片（arm64）。首版未经过 Apple Developer ID 签名或公证，可能被系统拦截；请先参考 Apple 官方说明 判断是否信任。

首版可以做什么

  • 运行期间采样前台应用，整理支持的浏览记录与可访问文件。
  • 提取 TXT、Markdown、CSV、ICS、DOCX、XLSX 和 PDF 的可读文字。
  • 索引照片、视频、音频原件；支持主动录音。
  • 按关键词、类型与日期搜索；可以打开来源、暂停采集与导出 JSON。

范围与测试

普通文件文字解析上限为每文件 12 MB；PDF 最多 30 页，Excel 最多 10 个工作表且每表 2,000 行。旧 DOC / XLS、较大文件与影音目前仅索引原件。没有扫描件 OCR 或录音转写。

本机 11 项自动测试通过；发布包经过启动、SQLite、原生前台接口、PDF 提取、签名完整性和安装包完整性检查。测试结果不代表所有设备和 App 均可读取。详见 验证记录。

微信加密聊天库不解密；未连接手机、受系统权限限制或未适配的内容会标明实际状态。订单、日程和浏览记录是待确认的生活线索。

版本与反馈

当前版本 1.0.0。Windows、Intel Mac 与手机独立安装包，以及多设备实时同步，尚未发布。
